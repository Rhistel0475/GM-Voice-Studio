# Prompt 7.3 — NPC Dialogue Engine

Implement an NPC Dialogue Engine for LiveBoard.

## Use
- NPC personality traits
- NPC role
- current scene
- environment state
- recent session events

## Functions
- buildDialogueContext(npcId)
- generateNpcDialogue(npcId, type)
- generateNpcDialogueAudio(npcId, text)
- recordNpcDialogue(npcId, text)

## UI Integration
NPC cards should support:
- Talk
- Rumor
- Threat
- Hint
