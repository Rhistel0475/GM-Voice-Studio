# Prompt 7.4 — Real-Time Session Logger

Implement a real-time session logger for LiveBoard.

## Log Types
- narration
- player action
- NPC dialogue
- system event
- GM note

## Requirements
- append log entries in real time
- support filtering later
- integrate with scene changes, dialogue, and encounters

## Functions
- addSessionLogEntry(entry)
- getSessionLog()
- getRecentSessionEvents(limit)
