# Prompt 7.6 — One-Click Encounter Launch

Allow the GM to launch encounters instantly from LiveBoard.

## Effects
- activate encounter state
- set environment state to combat
- populate enemies/NPCs
- add session log event
- suggest narration update

## Functions
- launchEncounter(encounterId)
- preloadEncounterContext(encounterId)
- endEncounter(encounterId)
