# Prompt 7.2 — LiveBoard Scene State Engine

Implement a Scene State Engine for runtime gameplay control.

## Scene State Should Track
- current active scene
- scene transitions
- encounter launch
- NPC state changes
- environment state changes
- narration refresh triggers

## Functions
- createSceneState(scene)
- setActiveScene(sceneId)
- setNpcState(npcId, state)
- launchEncounter(encounterId)
- setEnvironmentState(state)
- suggestNarrationFromState(sceneState)
- recordSceneEvent(event)
