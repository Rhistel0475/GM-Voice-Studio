# Prompt 3.1 — Voice Acting Presets

Create reusable voice acting presets for narration and NPC dialogue.

## Preset Traits
- tone
- pacing
- intensity
- style

## Example Presets
- Warm Narrator
- Grim Veteran
- Noble Scholar
- Whispering Oracle
- Rough Bandit

## Functions
- applyVoicePreset(voice, preset)

Allow presets to be attached to voices and NPCs.
