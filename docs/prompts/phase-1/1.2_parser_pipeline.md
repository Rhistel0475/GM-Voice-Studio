# Prompt 1.2 — Parser Pipeline Refactor

Refactor the ingestion parser into staged modules so it can output the new extraction schemas.

## Goal
Turn the parser into a clean staged pipeline that produces:
- ExtractedNPC
- ExtractedLocation
- ExtractedSceneSeed
- ExtractedCodexEntry

## Stages
1. normalizeDocument
2. chunkDocumentSemantically
3. classifyChunk
4. extractEntitiesFromChunk
5. linkExtractedRelationships
6. summarizeExtractionBatch

## Implementation Notes
- reuse existing parsing logic where possible
- do not do a giant rewrite
- keep source metadata flowing through the pipeline
- separate classification from typed extraction
- support confidence scoring

## Suggested Intermediate Types
- NormalizedDocument
- NormalizedSection
- SemanticChunk
- ChunkClassification

## Deliverables
- staged modules/functions
- improved pipeline types
- structured extraction output
- batch summary
- explanation of reused logic and remaining gaps
