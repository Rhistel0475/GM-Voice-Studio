# Prompt 1.5 — Live Board Context Builder

Implement the AI context builder for LiveBoard and related AI features.

## Goal
Create buildAiContext() that assembles scene-aware context automatically.

## Inputs
- active campaign
- active session
- active scene
- NPCs present in scene
- location information
- recent session log entries
- relevant codex entries
- campaign memories

## Output
Return a structured context object used by:
- scene narration
- NPC dialogue
- GM assistant
- scene direction suggestions
- summaries

## Requirements
- keep it modular
- keep it separate from UI components
- make it reusable across multiple AI services
