# Prompt 1.1 — Extraction Schemas

Implement structured extraction schemas for the ingestion pipeline.

## Goal
Create clean, production-minded TypeScript schemas for:
- ExtractedNPC
- ExtractedLocation
- ExtractedSceneSeed
- ExtractedCodexEntry

- ExtractionSourceType: "placeholder" | "demo" | "uploaded" | "generated"
