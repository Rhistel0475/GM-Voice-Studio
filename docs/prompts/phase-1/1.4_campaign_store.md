# Prompt 1.4 — Campaign Store Connection

Implement the shared Campaign Context store.

## Goal
Create a central state layer for:
- campaigns
- sessions
- scenes
- NPCs
- locations
- codex entries
- items
- factions
- encounters
- session log
- campaign memories
- timeline events

## Requirements
- use clear types
- expose selectors and actions
- avoid duplicate state
- keep store logic separate from UI components

## Key Functions
- setActiveCampaign
- setActiveSession
- setActiveScene
- upsertNpc
- upsertLocation
- upsertScene
- upsertCodexEntry
- addSessionLogEntry
- recordCampaignMemory

## Deliverables
- store implementation
- shared types wired into store
- selectors/helpers
- explanation of data flow
