# Prompt 1.3 — Confidence Review Queue

Implement a review queue for extracted entities before they are saved into the campaign store.

## Goal
Allow the GM to review extracted:
- NPCs
- Locations
- Scene Seeds
- Codex Entries

## Required Features
Each review item should show:
- extracted entity
- confidence level
- source excerpt
- source document info
- review status

## Actions
- Approve
- Edit
- Reject

## Confidence Rules
- high confidence -> may be auto-approved if configured
- medium confidence -> review suggested
- low confidence -> review required

## Requirements
- do not finalize persistence yet
- build the review model and UI state handling
- prepare for later integration into Prep/Codex screens
