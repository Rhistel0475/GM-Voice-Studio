# Prompt 2.5 — Document to Scene Generation

Convert extracted content into ready-to-run scenes.

## Inputs
- scene seeds
- locations
- NPCs
- hooks
- codex references

## Output
- title
- setup text
- location reference
- involved NPCs
- suggested narration
- conflicts
- hooks

## Function
generateSceneFromSeed(seed)

Scenes should be usable directly by LiveBoard.
