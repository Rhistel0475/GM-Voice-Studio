# Prompt 2.1 — NPC Portrait Generation

Implement NPC portrait generation and fallback handling.

## Goal
Automatically generate or assign portraits for NPCs.

## Requirements
- generate portrait prompts from NPC name, role, traits, and tags
- cache generated results
- use placeholder portraits if generation is unavailable
- store portrait URL with NPC records

## Function
generateNpcPortrait(npc)

## Deliverables
- portrait generation service
- placeholder fallback strategy
- NPC store integration
