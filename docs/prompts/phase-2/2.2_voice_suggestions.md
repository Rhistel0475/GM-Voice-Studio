# Prompt 2.2 — Voice Assignment Suggestions

Implement automatic voice suggestions for NPCs.

## Goal
Suggest voice presets based on:
- role
- personality traits
- tone hints
- accent hints

## Function
suggestVoiceForNpc(npc)

## Example Mappings
- merchant -> warm narrator
- bandit -> rough outlaw
- noble -> refined voice
- oracle -> whispering mystical tone

## Requirements
- show suggestions in NPC Workshop and Voice Studio
- allow GM override
