# Prompt 2.3 — AI Session Chronicle

Generate narrative summaries of completed sessions.

## Inputs
- session log
- scene seeds
- narration clips
- involved NPCs
- campaign memories

## Output
- session title
- narrative summary
- major events
- unresolved hooks
- optional player-safe version

## Function
generateSessionChronicle(session)

Store chronicle as a codex/session artifact.
