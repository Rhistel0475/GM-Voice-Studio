# Prompt 0.2 — LiveBoard Layout Blueprint

Implement the primary gameplay screen for GM Voice Studio.

## Critical Rule
The LiveBoard must fit entirely inside the viewport.
There must be NO page scrolling.
Panels may scroll internally if needed, but the page itself must not scroll.

## Layout
Top Banner (full width)

Below that, a 12-column grid:
- 2 columns: GM Tools
- 5 columns: Active Scene
- 2 columns: NPC Presence
- 3 columns: Codex Quick Reference

Bottom row content is embedded into the center/right sections.

## Required Panels
- GM Tools
- Active Scene
- NPC Presence
- Codex Quick Reference
- Session Log
- AI Assist
- Audio Controls

## Design Style
Keep the fantasy tabletop aesthetic:
- PanelFrame
- FrameCard
- IconBadge
- parchment cards
- gold borders
- dark background
- fantasy serif headings

Do NOT convert the UI into a generic SaaS dashboard.

## Technical Requirements
- Use CSS grid or Tailwind grid
- main wrapper: height 100vh, overflow hidden
- panels may use overflow auto

## Data Sources
Read from the shared campaign context:
- campaign.activeScene
- campaign.npcs
- campaign.codexEntries
- campaign.sessionLog
- campaign.campaignMemories

## Deliverables
- LiveBoardScreen with correct grid
- PanelFrame usage across panels
- no page scrolling
- short explanation of layout implementation
