# Prompt 0.1 — Folder Structure Alignment

You are a senior engineer working on the GM Voice Studio repository.

Goal: gradually align the repository with the target architecture without breaking the app.

## Target High-Level Structure

- lib/
- store/
- types/
- assets/
- docs/

## Rules
1. Do not perform a massive restructuring that breaks imports or runtime behavior
2. Move files incrementally and update imports safely
3. Create missing folders first
4. Move files only when the new location is clearly correct
5. If unsure, leave the file in place and document the suggested move

## Deliverables
- folders created
- files moved
- imports updated
- future moves not executed to avoid breakage
