# Prompt 4.1 — Adventure Document Ingestion

Improve document ingestion so full adventures can be processed reliably.

## Requirements
- support PDF, DOCX, and Markdown
- preserve headings and page numbers
- identify major sections automatically
- store document metadata for traceability

## Functions
- ingestAdventureDocument(file)
- extractStructuredSections(document)

The output should feed Codex, NPC Workshop, and scene generation.
